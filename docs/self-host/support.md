# Support

Colliedesk is licensed under the AGPL-3.0 and provided without warranty. HC Labs does not offer
support for self-hosted servers at this time: we do not answer installation, infrastructure or
configuration questions, and there is no paid support plan. You run the server and take the risk
of running it.

If you really need help, email [support@colliedesk.com](mailto:support@colliedesk.com). Say which
version you run (`collie version`, see [troubleshooting](troubleshooting.md#which-version-do-i-run))
and include the relevant lines of `docker compose logs server`, without secrets.

You can still report problems in the product:

- **Bugs:** open an issue at
  [github.com/colliedesk/colliedesk/issues](https://github.com/colliedesk/colliedesk/issues).
- **From inside the app:** the [problem report](../user/problem-reports.md) dialog offers to open
  a GitHub issue with the details filled in.
- **Security problems:** do not open a public issue. Follow the
  [security policy](../../SECURITY.md).

To have HC Labs run the server, its upgrades and its email delivery, use
[Colliedesk Cloud](https://colliedesk.com). See [migrate to Colliedesk Cloud](migrate-to-cloud.md).
