# Support

Colliedesk is licensed under the AGPL-3.0 and provided without warranty. For a self-hosted
server you run, these are the ways to get help:

- **Bugs and questions:** open an issue at
  [github.com/colliedesk/colliedesk/issues](https://github.com/colliedesk/colliedesk/issues). Say
  which version you run (`collie version`, see [troubleshooting](troubleshooting.md#which-version-do-i-run))
  and include the relevant lines of `docker compose logs server`, without secrets.
- **From inside the app:** the [problem report](../user/problem-reports.md) dialog offers to open
  a GitHub issue with the details filled in.
- **Security problems:** do not open a public issue. Follow the
  [security policy](../../SECURITY.md).

To have someone else run the server, upgrades and email delivery, use
[Colliedesk Cloud](https://colliedesk.com).
