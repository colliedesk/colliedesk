# Self-host Colliedesk

Colliedesk is open source and free to run on your own server. These pages are for the person who
runs that server. How to use Colliedesk once it runs is in the [user guides](../user/README.md);
they are the same for Colliedesk Cloud and for your own server.

A self-hosted server has every feature of the product. It has no billing, no free trial, no
sign-up page and no ready-made `support@<workspace>.colliedesk.com` address; those belong to the
hosted [Colliedesk Cloud](https://colliedesk.com). You run updates, backups and email delivery
yourself.
